We detail a semi-automatic pipeline for collecting temporal satellite imagery using OpenStreetMap metadata. The public repository provides scripts for extracting candidate construction-site regions and downloading imagery over time, plus a sample dataset and notebook. It does not include a general annotation application or a train/validation/test split exporter.
